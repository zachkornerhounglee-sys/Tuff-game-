Hide & Seek Murder Mystery 3D (first person)
Keep index.html and the assets/ folder together (models are packed as assets/*.js).
Works by double-clicking index.html, or on GitHub Pages (upload index.html + assets folder).
If a model ever fails to auto-load, use "Load models from your computer" ONCE:
the game remembers the files in your browser, so you won't need to pick them again.
Controls: WASD move, Shift run, mouse look, click to shoot (Sheriff) or stab (Murderer).
